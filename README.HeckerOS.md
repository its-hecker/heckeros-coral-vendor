# HeckerOS coral vendor

Imported unchanged from the existing PixelOS coral vendor snapshot in UPSTREAM_SOURCE.json. Hardware blobs, extraction metadata, install ownership fixes and original licenses are retained. All 11 radio payloads are fetched from the existing public Git LFS read endpoint in .lfsconfig and verified against Android.mk by the LFS workflow. No external LFS upload credentials are required for read-only builds.

Use the [HeckerOS coral local manifest](https://github.com/its-hecker/HeckerOs-localmanifest) for pinned source/build setup. ROM customizations, FaceID and Motion Sense integration, GCam, Settings and branding belong to [HeckerOS](https://github.com/its-hecker/HeckerOS). Full ROM build and coral validation are pending.
